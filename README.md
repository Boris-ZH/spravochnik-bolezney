# Справочник болезней

Одностраничный научный лендинг о восьми заболеваниях. Статический сайт без сборки и зависимостей:
достаточно открыть `index.html` в браузере.

## Структура

```
index.html          разметка страницы (шапка, герой, содержание, контакты, попап)
styles.css          оформление, адаптив, анимации
script.js           данные о болезнях, рендер карточек, попап, подсветка навигации
images/             исходные иллюстрации (PNG, 2048 px)
images/thumbs/      превью для карточек (WebP ~760 px)
images/large/       крупные изображения для попапа (WebP ~1500 px)
assets/emblem.webp  эмблема «чаша со змеёй» для шапки героя
assets/emblem-source.jpg  исходник эмблемы, сгенерированный flux.2-pro
assets/mark.svg     иконка сайта
preview/            скриншоты страницы (десктоп и мобильный)
tools/              служебные скрипты (оптимизация, аудит, скриншоты)
```

## Как открыть

Просто откройте `index.html` двойным кликом. Для проверки по локальному адресу можно запустить
любой статический сервер из этой папки, например:

```powershell
python -m http.server 8000
```

и перейти на `http://localhost:8000`.

## Что реализовано

- полупрозрачная «стеклянная» шапка, закреплённая при прокрутке;
- кнопки «На главную», «Содержание», «Контакты» с плавным переходом к разделам;
- заголовок, подзаголовок и медицинская эмблема (сгенерирована моделью flux.2-pro);
- раздел «Содержание» — восемь карточек с превью, которые увеличиваются при наведении на десктопе;
- попап: крупное изображение, категория, название, описание и ключевые факты;
- закрытие попапа по крестику, клику/тапу вне окна и клавише Esc, блокировка прокрутки страницы;
- раздел «Контакты» с тестовыми данными и ссылкой PaMaTiMiLiS.com в подвале;
- адаптив: от 320 px до широких десктопов, тач-таргеты ≥ 44 px, поддержка `prefers-reduced-motion`.

## Служебные скрипты

```powershell
# превью и крупные версии из исходных PNG
python tools/optimize_images.py

# подготовка эмблемы из сгенерированного исходника
python tools/prepare_emblem.py

# статическая проверка ссылок, id, классов и CSS
python tools/audit_static.py

# runtime-проверка рендера карточек и попапа (Node, без браузера)
node tools/smoke-js.mjs

# проверка вёрстки и попапа в headless Edge (нужен браузер)
node tools/audit-layout.mjs

# переснять скриншоты в preview/
node tools/capture-preview.mjs
```

Скрипты с headless Edge запускаются только при доступе к IPC браузера; в обычных условиях
вёрстка проверяется через `audit_static.py` и `smoke-js.mjs`.

## Примечания

- Контакты и ссылка `PaMaTiMiLiS.com` — тестовые; ссылка пока нерабочая.
- Материалы справочника носят информационный характер и не заменяют консультацию врача.
- Шрифты Inter и JetBrains Mono подключаются с Google Fonts; без сети используется системный шрифт.
